# Local complete-character pilot implementation plan

Keep all existing production artwork and prior releases. No automatic commits, external generation, purchases or installed-app changes.

1. Validate the isolated native ARM bpy runtime with non-animal RGBA renders and stable alpha/hash checks.
2. Author one connected kitten skin, real short fur, embedded eyes and physical face details using the actual whole neutral reference. Preserve fixed rest attributes and random seeds. Export a complete neutral render and authoring scene/provenance.
3. Independently inspect the actual neutral at 256 and enlarged sizes. Iterate geometry, fur and projection when it fails; do not render a full cycle before this gate.
4. Use the independently checked pure-math gait fixture to animate fixed links and persistent skin/fur, with world-fixed feet and screen-X-compatible camera. First inspect a sparse pose sample and verify the visible skin follows the intended contacts.
5. Render 128 actual phases if the sparse sample is acceptable. Record source hashes, phase, camera basis, fixed scale, contact coordinates, unique raster count and raw output. Phase 1 is a diagnostic seam render, never a duplicate new source phase.
6. Inspect all actual frames and edges, normal/slow whole-picture playback, identity/fur continuity, visible sole contact and final projected stride. Review exact source selection separately from normal GPU pacing. Only accepted sources may begin a production integration plan.
