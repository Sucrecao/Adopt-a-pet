# Complete-frame Line Pets Implementation Plan

> **For agentic workers:** Use subagent-driven-development for independent source, presentation and QA tasks; root owns controller and integration. Track results in `.artifacts/line-pets/progress.md`.

**Goal:** Deliver cohesive drawn dog and cat companions whose whole-frame actions join smoothly and whose planted paws agree with fractional visual travel.

**Architecture:** An offline vector author exports complete PNG atlas cells and physical landmarks. A dedicated controller selects whole frames and phase-specific settling tracks. A fixed native host presents the logical companion at fractional coordinates with one drawing clock.

**Tech Stack:** Existing JavaScript, React, Canvas 2D, Electron, PNG atlases, Node tests and Playwright.

## Global Constraints

- Preserve original source assets, existing user changes and old release archives.
- Each displayed pose is one whole image; no runtime parts or crossfades.
- `meta.version=7`, `authoring='line-pet-v1'`, `renderMode='discrete-whole-frame'`.
- New authored metadata can hold at most 8192 frames and 160 pages; old v7 limits remain unchanged. Complete atlas cells are128px, rasterized from512px whole vector scenes and registered at256px canonical size. Decoded bitmaps are loaded as needed and released against a32MiB budget.
- All nine clips remain; turn is exactly 800 ms.
- Freeze picture and travel on pause, reduced motion and dragging.
- Do not purchase, install into the user's app or change its stored profile.
