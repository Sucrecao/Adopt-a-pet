# 连续姿势播放修复

用户要求继续解决明显卡顿，延续已授权的写实可爱、连续 2.5D 动作和 Mac / Windows 桌面伙伴方向。

## 证据与选择

隔离 Electron 中页面 rAF 中位间隔 16.7 ms、P95 17.6 ms，原生移动中位 17.41 ms；没有发现主要线程长时间停顿。现有播放器走路每 100 ms 硬换一张图，伸展与小跳每 650–700 ms 硬换一张图。仅增加刷新次数无法改变姿势跳变。刚领养后转向还会重建播放器，把步态重置至第一帧。

保留现有图集，采用相邻姿势的双向位移场插值，按显示刷新频率绘制中间姿势；转向与动作时钟独立。直接淡入两张图会出现双脚和双轮廓，完全重做 3D 则超出此次卡顿修复范围。位移场在开发阶段从现有透明图集计算，程序运行只读取本地数据，不增加 Python/OpenCV 运行依赖。

## 播放与绘制

纯时间线输出当前帧、相邻帧和连续进度。闲时动作和显式互动沿用原有时长与语义。动画控制器在宠物身份不变时持续存在，朝向和普通状态广播不重置步态；暂停与减少动态效果停止播放，恢复不会追赶停顿时间。

Canvas WebGL 在两张姿势之间进行双向变形，再混合颜色与透明度。每张图先使用现有脚底注册偏移，插值过程维持地面基准。动作切换使用上次实际绘制画面的短过渡，消除新姿势突然弹出的效果。绘图在 rAF 内进行，不再每帧触发 React 状态更新。静态领养缩略图只绘制一次。

素材加载失败保留旧图集；WebGL 不可用时使用 Canvas 2D 连续混合，透明窗口、鼠标交互、拖拽、养成与现有坐标异常修复保持可用。位移场为二进制数学数据，原图不修改。

## 验收

测试必须证明相邻刷新帧画面实际变化、正常转向不重置步态、慢动作没有 650 ms 的姿势硬停顿、暂停/减少动态效果停止变化、重新加载和重复互动正常。检查三种动物的完整走路、伸展、小跳和动作切换，排除串格、脚底跳动与明显重影。保持用户资料，更新至 0.2.2 并重新生成三个 ZIP；在 Apple Silicon Mac 运行打包后的实测。
