# 屏边小伙伴 / Desktop companions

用户已批准跨平台桌面程序、写实可爱的猫狗鹦鹉，并补充：宠物可在屏幕中央活动，互动要有趣。

## 产品行为

- 初次启动展示中文领养面板，三个物种各有名字、性格和互动说明。可修改名字、领养或更换宠物。
- 宠物使用带 alpha 的写实动画图集，透明、无边框、置顶的小窗口显示在桌面。猫狗行走，鹦鹉飞行；自由活动与贴边模式可切换，也可拖到中央。
- 抚摸触发爱心与回应；喂食恢复饱腹；逗猫棒、追球、飞行游戏触发追逐；休息恢复精力。重复操作存在短冷却，避免数值无限增长。
- 领养面板包含安全的互动预览：宠物跟随玩具目标、反馈气泡、心情、饱腹与精力。浏览器模式明确提示其为预览，桌面模式使用真实透明宠物窗口。
- 可调整宠物大小、活动范围、声音、置顶与暂停。托盘提供显示/隐藏、面板和退出。设置与养成状态本地保存。

## 结构与数据

React + Vite 实现领养/控制面板与透明宠物渲染；Electron main 管理窗口、显示器、托盘和文件存储；context-isolated preload 只暴露白名单 IPC。纯 JS core 管理状态、互动与坐标约束，Node test runner 测试。

UI 和 Electron 共用 `src/core/pets.js`、`src/core/state.js`、`src/core/geometry.js`。状态包含 species、name、adopted、stats、settings、action、updatedAt。主进程是桌面模式状态唯一来源；浏览器预览使用同样的 reducer 和 localStorage。

宠物小窗口只覆盖必要区域；主进程依据已注册的宠物椭圆与工具栏矩形决定是否接收鼠标，空白区穿透。运动坐标采用 DIP 和 display.workArea，支持拖拽跨屏与显示器改变后重新约束。

## 视觉

浅雾紫 `#f7f7fb`、墨色 `#282637`、紫丁香 `#8c73d9`、浅紫 `#eee8fa`、草绿 `#6c9b7d`、桃粉 `#f2a9b8`。圆润系统中文字体配 Georgia 英文展示字。侧栏控制台 + 领养面板 + 宽幅互动桌面；记忆点是写实宠物在模拟桌面中央与玩具互动。

## 验证与限制

测试涵盖状态校验、冷却与数值边界、离线衰减、窗口负坐标/多屏约束、IPC 来源和输入校验。构建验证 React 生产包，Electron 运行验证透明窗口、领养、互动、拖拽与保存。Mac 可在本机验证；Windows 安装包通过 Windows CI 构建并需 Windows 实机确认透明、DPI 与跨屏表现。真实全屏应用的自动识别不在首版范围；托盘可隐藏。
