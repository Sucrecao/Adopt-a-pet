# Complete-frame line pets

The user delegates execution and explicitly permits simple drawn dogs and cats. This supersedes the former plush-appearance requirement; whole-character pictures and natural motion remain required. Work proceeds in the existing checkout so the running preview and retained artifacts stay usable. No purchases, profile changes, commits, or replacement of old release archives are needed.

## Chosen approach

Author a consistent rounded dog and cat as complete vector scenes, then rasterize every distinct pose into transparent PNG atlas cells. A side view gives a clear ground line and measurable planted paws. This avoids identity changes between generated stills. The retained photo route is available in source history and the parrot keeps its current route. Video remains unavailable in the connected free plan; the rejected plush model is not reused.

The new assets use discrete whole-frame metadata with `authoring: line-pet-v1`. All nine actions remain available. Walking advances solely with the displacement of the presented whole picture. Each walk pose has its own authored settling sequence; care cancellation retraces complete frames to a shared neutral pose before beginning another action. Rest entry and exit are full-frame tracks. A turn is 800 ms and terminates at the correctly mirrored neutral picture. No runtime limb assembly, image warp, optical flow, crossfade, or synthetic duplicate frames.

## Presentation

For the new dog and cat, a fixed transparent native host contains a logical companion box. A renderer-owned display tick computes fractional travel, samples the matching complete pose and commits both together after a successful draw. Native code receives bounded, epoch-tagged committed geometry for pointer regions and drag. Size changes, dragging, pause, display migration and failure rebase the presentation clock. The original parrot path remains supported.

## Acceptance

Check neutral art, every exported pose and all adjacent joins. Independently measure stance-paw world coordinates, loop closure and complete-image bounds. Exercise start/stop at arbitrary phases, action interruption, rest, mirror, pause, drag and size changes. Record finite browser and native playback timings and actual pixel observations. Passing mathematics alone does not establish natural movement; visual review is required. Only verified new sources are made the default and a reviewable preview is shown.
