# 摸头撒娇与起身提醒 0.5.6

鼠标在两犬无道具姿态的头部停留 400 毫秒后，重播适合当前姿态的原作并轻轻向光标蹭两下，出现短暂亲切话语。同一次停留只回应一次；离开与冷却后才能再次触发。暂停、拖动、菜单、深夜及减少动态效果时安静。检测在鼠标离开后停止轮询。

“每30分钟提醒起身”默认开启，设置可关闭并保存。活跃运行半小时后由桌面宠物显示一份气泡，12 秒后自动收起，也可点“知道啦”。互动期间等待，主动互动会让提醒让位；提醒期间宠物停稳。暂停、隐藏、系统休眠和深夜清除积压，恢复后重新计时。
