# PawPal · 屏边小伙伴

Mac / Windows 的桌面宠物程序：领养马尔济斯、金毛或鹦鹉青柠，在透明窗口里陪伴与互动。Maltese 和 Golden Retriever 使用 Moonlab 的原作画面与原始动画，在原地播放并支持拖动摆放；青柠保留飞行和照顾互动。

## 当前角色 · 0.5.5

领养列表仅保留马尔济斯、金毛和青柠。旧奶糖、豆包存档迁移为马尔济斯，保留自定义名字、状态和设置。

## Maltese & Golden Retriever 原作动画

两位角色各有 24 段原作动画，共 741 帧。保留原始完整画面、透明背景、道具、播放时长和循环次数。点击“换个表情”才展开原画缩略图菜单，选择后收起；支持暂停、调整大小和拖动摆放。原作完整播完后短暂停留约 0.9 秒，再回到放松待机。醒着时每隔 14–24 秒偶尔有一个原作小反应；睡觉、暂停和拖动时保持安静。

所有时段显式使用北京时间：07:00 早安招手，10:00 安静陪伴，12:00 开饭，14:00 回到日常，19:00 拥抱撒娇，23:00 睡觉。白天和晚间每隔 3–5 分钟偶尔说一句亲切话，每句显示 6 秒；晚上更多关心和抱抱，深夜不周期提醒。暂停、拖动、隐藏、减少动态效果及页面不可见时安静等待，菜单打开时不插话。

官方参考：[Maltese](https://store.line.me/stickershop/product/24856130/en) / [Retriever](https://store.line.me/stickershop/product/24856095/en)。源预览保存在 `public/pets/*-original-source-*.png`，逐帧无损导入脚本为 `scripts/import-original-puppies.py`。验证记录见 `docs/verification-moonlab-original-0.5.2.md`。

## 启动

已经打包的试用版在 `release/`：

- Apple 芯片 Mac：解压 `PawPal-0.5.5-mac-arm64.zip`，打开 `PawPal.app`。
- Intel 芯片 Mac：解压 `PawPal-0.3.2-mac-x64.zip`，打开 `PawPal.app`。
- Windows x64：解压 `PawPal-0.3.2-win.zip`，运行 `PawPal.exe`，保留同目录其他文件。

0.5.5 Apple 芯片 Mac 包使用本地 ad-hoc 签名并通过原生桌面检查。旧版 Intel Mac 和 Windows 包尚待对应系统实测。

Apple 芯片 Mac 与源码已更新到 0.5.5；Intel Mac / Windows 下载包暂保留 0.3.2。

从源码运行：

需要 Node.js 22.12+（建议 22 LTS）与 npm。

```sh
npm install
npm run dev
```

这会启动真实 Electron 桌面程序。选择宠物、取名字并领养后，透明宠物窗口出现。领养面板关闭后程序留在托盘/菜单栏，点击爪印重新打开；托盘菜单可显示/隐藏宠物、暂停或退出。

仅查看网页互动预览：

```sh
npm run dev:web
```

访问 `http://127.0.0.1:5173`。浏览器会显示“浏览器预览”，宠物只在页面里的模拟桌面活动。网页不能生成真正的系统桌面透明窗口。

## 互动

- v0.4.5 按用户选择恢复完整原画逐帧动画，保留写实毛绒外观。每种宠物复用128张完整姿态，其中走路/飞行32张；每次只画一个完整源图，统一缩放、位移与整体镜像，不拼接头、身体或腿，也不生成光流、局部变形或混合帧。三页全部加载通过检查才启用；失败时显示完整静态原图并暂停自动移动。起步播放两张完整过渡画面后才放行移动，实际走过的距离仍驱动步态；转身、暂停、拖动、减少动态效果及移动中玩耍的时钟保持一致。原画里较大的姿态切换和落脚偏差仍保留，不把恢复方案等同于步态仿真认证。预览可慢放和逐帧查看。下列版本描述作为历史记录保留。
- v0.4.4 修正猫狗落脚与移动的对应关系：保留原来的完整毛绒图片，以实际走过的距离驱动四足支撑、摆腿和抬脚；支撑脚相对身体后移，抵消窗口前进。头部和上半身保留原图，行走使用完整站立图的局部连续变形，不再循环那32张无法保持落地的行走图。开始与停止依次抬脚放置，桌面及预览都等首步准备结束再移动。新增61条通过真实GPU画面检查的动作连接，支持途中换动作、取消、重复休息及暂停恢复；小狗入睡去掉了错误的站立姿态。转身动作仍为800毫秒，出口必要时继续等待约160毫秒的首步准备。较大的转面和翅膀遮挡变化共24处保留完整原帧切换；任意照顾动作返回被中断的部分转身仍有有限衔接。猫狗转身本身也沿原图姿态播放，没有声称重画了完整三维动作。
- v0.4.3 独立调整猫、狗和鹦鹉的行走/飞行节奏。步幅分别为 96、112、80 个角色坐标单位，移动速度随实际显示尺寸缩放，预览和桌面共用速度规则；实际走过的距离仍决定步态进度。其他动作在适合插值的完整姿态之间生成过渡画面，随屏幕刷新播放，保留原来的毛绒素材和动作时长。大幅转面或遮挡变化处保留完整原帧，避免补帧重影。睡觉途中取消会从当前过渡姿态回转；猫狗转身仍为 800 毫秒。过渡数据或 GPU 不可用时显示完整的原始姿态。
- v0.4.2 将行走/飞行从 16 个完整姿态进一步细化到 32 个，使用单独的透明图页。32 个步态相位等距排列，一圈仍为 1060 毫秒、实际位移步幅仍为 64，保留其他动作和衔接姿态。对齐头部位置并平滑整只角色的轻微起伏，减少逐帧抖动；鹦鹉固定头部位置，让翅膀逐渐完成一次拍动。三张图全部解码并通过验证后才启用新渲染，素材缺失时保留完整的旧动画回退。
- v0.4.1 保留写实毛绒外观，每种宠物由 45 个完整姿态增加到 96 个：待机 12、睡觉 4、行走/飞行及转身各 16、抚摸/喂食/梳理/伸展各 8、跳跃 10，另有 6 个衔接姿态。停步和入睡有完整身体的过渡，途中取消会从当前姿态返回；各互动的动画时长与操作时长一致。猫、狗和鹦鹉各有待机、行走/飞行、转身、抚摸、喂食、梳理、伸展、跳跃和睡觉动作；每帧是一只完整的动物。待机采用本机 Codex 史努比的 6.6 秒节奏，行走按实际位移推进；猫狗转身仍占用 800 毫秒，鹦鹉直接切换飞行方向。各动作素材共用比例和落脚基线，跳跃保留腾空高度，飞行按头部位置配准。下面的 0.3.x 关节动画说明是旧版本及素材缺失时的回退行为。

## 构建

```sh
npm run build         # renderer production bundle
npm run pack          # 当前系统的可运行应用目录，输出 release/
npm run dist:mac      # 在 Mac 构建 arm64/x64 DMG
npm run dist:win      # 在 Windows 构建 x64 安装程序
npm run dist:win:zip  # Windows x64 便携 ZIP；可在 Mac 上构建
```

Mac 和 Windows 的安装包由 `.github/workflows/build.yml` 分别在对应系统构建（手动触发或推送 v 开头标签）。不自动发布。默认构建未提供开发者签名，分发时可配置 electron-builder 的证书与 notarization。

Windows 便携版解压后运行 `PawPal.exe`；保留同目录的其他文件。便携版跳过 Windows 可执行文件资源编辑与签名，可在 Mac 构建；正式 NSIS 安装包仍建议 Windows CI。

## 验证

```sh
npm test
npx playwright install chromium
npm run test:ui
npm run test:desktop
```

测试包含状态校验、互动冷却、衰减、负坐标/多屏范围、IPC 白名单与用户完整流程。新动画测试检查实际GPU脚底像素与世界位移、逐脚首步与收脚、动作中断首帧一致性、原生首步就绪握手、800 毫秒转身、暂停恢复、重复互动、素材验证与物种切换；旧关节测试继续覆盖回退路径。真实桌面测试使用独立临时存储检查三种宠物的透明窗口、完整角色画布、互动画面、实际移动及转身、暂停、拖拽、减少动态效果、大小设置和退出后的数据保存。

Windows 透明效果、DPI、多屏拔插与全屏行为需要 Windows 实机确认。第三方全屏应用没有自动隐藏检测；可通过托盘隐藏宠物。Mac 的跨 Space 显示通过 Electron 原生窗口 API 实现。

## 项目结构

- `src/core/`：纯状态转换、宠物资料与显示器范围逻辑。
- `src/`：React 控制面板、互动预览与宠物渲染。
- `electron/`：透明窗口、鼠标穿透、拖拽、活动、托盘、持久化和隔离的 IPC。
- `public/pets/`：三种宠物的透明 PNG 动作图集与本地姿态光流数据；原始图集提示词在 `docs/asset-prompts.md`，新关节素材提示词在 `docs/rig-asset-prompts.md`。
- `src/rendering/`：Canvas 2D 关节动画，以及旧图集的 WebGL/Canvas 回退。

桌面状态保存在 Electron `userData` 目录的 `companion.json`（Mac 通常为 `~/Library/Application Support/pawpal-desktop/`；Windows 通常为 `%APPDATA%/pawpal-desktop/`），网页预览使用浏览器 localStorage。无需账号或服务器。
